# Glossário (tom TSE / democracia cidadã)

Linguagem **formal jurídico-institucional**, simples e sem jargão desnecessário.

| Termo | Uso no Painel |
|-------|----------------|
| Eleição | Processo de escolha de representantes ou propostas |
| Plebiscito | Consulta prévia à elaboração de acto normativo |
| Referendo | Consulta para confirmar ou rejeitar acto |
| Escrutínio | Acto de votação / recolha da vontade |
| Apuração | Contagem e totalização auditável dos votos |
| Certificação | Ato de assinar e publicar o resultado (JSON + PDF) |
| Parcela | Parte do segredo (share) sob custódia de autoridade |
| Autoridade Eleitoral | Detentor(a) de parcela / official |
| Administrador Eleitoral | Opera o site pela comissão/mesa |
| Gestor Voto Eletrônico | Operação RelataSoft / P&D |
| Eleitor | Quem vota — apenas no front |

Referência contínua: glossário e comunicações do [TSE](https://www.tse.jus.br/).
