# Gestor pelo Cliente

O **Gestor pelo Cliente** (`ve_gestor`) opera o Painel com as mesmas capacidades administrativas do Administrador Eleitoral neste produto.

## Notas

- O slug WordPress permanece `ve_gestor`
- Em implantações E3, cada site tem sua própria conta gestor (mesmo login inicial possível, mas **sem sincronização** entre sites)
- Consultar também **Implantação E3 (3 WordPress)**
