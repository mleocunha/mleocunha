# Setup — Custom GPT (ChatGPT Plus)

1. Crie um GPT **privado**.
2. Cole `custom-gpt/instructions.md` nas instruções.
3. Adicione conversation starters de `custom-gpt/conversation-starters.md`.
4. Em Actions, importe `custom-gpt/openapi.yaml`.
5. Authentication: Bearer token — use o token de 256 bits (não o hash).
6. Server URL: `https://openclaw-api.relatasoft.com.br`
7. Publique apenas para você / convidados autorizados.

Não use MCP privado nem planos Business/Enterprise como requisito.
